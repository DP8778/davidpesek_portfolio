# Redesign_4

Redesign_4 uchovává zvolenou variantu celé stránky z Redesign_3 a napevno používá Prism Corners v hero. Původní Redesign_3 zůstává jako prostor pro porovnávání variant.

Ve Storybooku obsahuje:

- celou stránku ve světlém a tmavém režimu,
- tabletový a telefonní náhled,
- Digital Call case study,
- Lens case study,
- telefonní náhledy obou case studies.
